## Project Description

This is a React-based Library Book Manager application.

It allows users to:
- View all books.
- Filter books by genre.
- View complete book details.
- Issue available books.
- Return issued books.
- View issued books.

## Technologies Used

- React
- Vite
- React Router
- JavaScript
- CSS

## Installation

Install the project dependencies:

npm install

Install React Router:

npm install react-router

## Run Project

npm run dev
